## What v0.6.0 added

- **Automatic Orca round-trip** (`watch_folder.py`, `OrcaRoundTrip.tsx`). One
  user-chosen folder, polled only while the page is open. A file is offered only
  once its size has settled and it ends the way a finished job ends.
- **Project to slice provenance** (`provenance.py`). Verdicts `confirmed`,
  `likely`, `ambiguous`, `no_match`, `unknown`. Object names compare as a digest
  so no model name leaves the file. A filename is weak corroboration only and can
  never carry a verdict; two equally good candidates return no answer.
- **Material provider seam** (`material_providers.py`). Stock printer by default,
  optional read-only Spoolman on the local network. The printer stays
  authoritative about what is in a slot; a provider may only add what the machine
  cannot know. Nothing required, nothing written back, disagreements reported.
- **Material sufficiency** in `material_plan.py` — a blocker when the tracked
  spool holds less than the job needs, and honestly unknown on a stock printer.
- **Project Cockpit** (`Cockpit.tsx`, route "This print"). Three stages on one
  surface. In Simple mode it takes the place of "Check my model", which moves to
  More tools; Simple mode is capped at five items and a test enforces that.
- **Upload confirmation** (`moonraker.confirm_upload`). Studio used to report
  success when the printer had only accepted the bytes; metadata is parsed
  asynchronously, so the job could be present and not yet startable. Uploads are
  now confirmed against the printer's own metadata with one metascan, and a
  same-named file of a different size is caught.
- **G-code reader guard** — a 3MF handed in where G-code was expected used to
  produce a report that looked empty for no reason.
- **Evidence guard widened** to read prose as well as tables, to check the demo's
  length against the recording's own mvhd header, the screenshot folder against
  the released version, and that the README names the current release.

## Known limitations, stated publicly and still true

Windows only. Installer unsigned. Purge cannot be attributed to a single object.
Nozzle diameter is not readable from the job. Free storage is not exposed by
stock firmware — traced, not assumed, and reported as unknown. Painted colour
cannot be classified. Provenance can only answer `unknown` when a job carries
neither object names nor colour data. Remaining filament is known only where
something tracks it. Prusa projects are read in full but not yet fully carried
into a prepared copy.

## Not started, and deliberately so

- Extended firmware capability provider — needs a firmware build to test against.
- Prusa preparation beyond reading.
- U1Hub adapter — waiting on a stable public local API. Do not scrape its private
  files and do not copy it.

## The three genuine human gates

Everything up to each of these is already prepared.

1. **Send the drafted Innovation Fund listing correction.** The listing still
   carries an old description and cover image. The draft is written; sending it
   is the maintainer's to do.
2. **Post the community update.** Written and reviewed. Posting is under the
   maintainer's identity. No request for stars, no request for votes, no
   Innovation Fund lobbying.
3. **Submit the SignPath application** for a signed installer. The form accepts
   terms on the maintainer's behalf.

## Standing rules that bite most often

- Studio never slices, never takes autonomous control of a printer, never
  uploads anything anywhere, and never modifies an original file.
- Never force-kill a slicer, printer or user GUI process. Only processes this
  session started, tracked by PID.
- No local paths, usernames, hostnames, printer addresses or private model names
  in tracked files or screenshots. Anonymise evidence at the source.
- Unknown stays unknown. Withdraw an unprovable claim rather than patching it.
- Do not publish a prerelease to show progress, and do not hard-code a number
  that `evidence.json` already carries.
